官网 AI 客服接入演示

最小可用版只需要一个嵌入页、留资表单和转人工入口，依托 FastGPT + 智谱 GLM-5.1 即可快速降低人工成本。

嵌入式客服模拟器

模拟官网悬浮客服反馈链路，支持文字输入与智能预热提示。

留资表单

必要时由 AI 推动并收集客户联系方式与项目意向。

提交后会同步到后台 CRM/Lark 群，并推送到人工客服。

转人工入口

当智能判断无法完成或用户要求转人工时可立即触发。

遇到高复杂度项目、敏感政策或报价需求时，请点击 “人工协助”，我会立刻记录并提示人工客服接入。

接入说明

  • 接口假定部署在 `/api/ai/chat`，接受 `{ question, history }`。
  • FastGPT 负责对接 GLM-5.1/Embedding-3，moderation + GLM-4-Flash 质检。
  • 留资表单可 POST 到 `/api/ai/lead`，包含 `name`、`contact`、`product`。
  • 人工转人工入口调用 `/api/ai/handoff`，返回 `status: "queued"` 为准。
  • 所有请求按 JSON 交互，响应结构为 `{ answer: string, sessionId?: string }`。
  • 若页面部署在静态 CDN，只需合并 `css/style.css` 与 `js/app.js`。
