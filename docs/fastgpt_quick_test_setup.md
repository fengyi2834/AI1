# FastGPT 空白后台快速配置说明

这份说明用于把当前空白的 FastGPT 后台，快速配置成一个“可以测试问答的客服应用”。

## 你现在的现状

- FastGPT 已启动：`http://127.0.0.1:3100`
- 默认账号：`root`
- 默认密码：`1234`
- 后台数据库当前是空的：还没有应用，也没有知识库
- 系统里已经识别到至少一个模型：`glm-5`

## 目标

在 FastGPT 后台里手动完成两件事：

1. 建一个测试知识库
2. 建一个测试客服应用，并把知识库挂进去

做完后，你就能直接在 FastGPT 里提问测试。

## 第一步：创建测试知识库

进入 FastGPT 后台后：

1. 打开“知识库”
2. 点击“新建知识库”
3. 名称填：`广西亿库客服测试库`
4. 创建完成后，进入这个知识库
5. 选择“导入文件”或“上传文档”
6. 上传这个文件：

`C:\Users\Administrator\Desktop\AI1\data\import_ready\demo_customer_service_faq_zh.md`

7. 等待解析完成
8. 看到知识条目后，说明知识库已经可用

## 第二步：创建测试客服应用

回到应用页后：

1. 点击“新建应用”
2. 类型优先选“对话应用”或“简单应用”
3. 名称填：`广西亿库 AI 客服测试`
4. 在“系统提示词 / System Prompt”处，粘贴这个文件内容：

`C:\Users\Administrator\Desktop\AI1\config\fastgpt\quick_test_system_prompt.md`

5. 在模型选择里，优先选择：
   - `glm-5`
   - 如果你后台里还能看到其他智谱模型，也可以选更合适的一个聊天模型
6. 打开知识库引用，把刚创建的 `广西亿库客服测试库` 关联进去
7. 检索条数先设成 `3`
8. 相似度阈值如果页面有这个配置，先用默认值
9. 保存应用

## 第三步：直接测试

应用创建完后，可以直接用下面这些问题测试：

### 测试问题 1

这个板材适合新房吗？

预期：

- 会回答“适合家庭和商业空间”
- 会补充“新房建议配合通风和检测”

### 测试问题 2

会不会帮助除味？

预期：

- 会回答“在合适条件下可以辅助吸附异味”
- 不会夸大成绝对承诺

### 测试问题 3

你们能不能直接报价？

预期：

- 应该倾向转人工
- 不应该胡乱报具体价格

## 如果你看到“模型列表为空”

先不要慌，这通常说明后台模型配置页还没手动确认。

优先检查：

1. `.env.local` 里真实 `CHAT_API_KEY` 是否已经填好
2. FastGPT 是否已经重启
3. 后台模型页里是否出现 `glm-5`

## 当前最短测试路径

如果你只想尽快验证“客服能不能用”，最短路径就是：

1. 上传 `demo_customer_service_faq_zh.md`
2. 新建一个对话应用
3. 粘贴 `quick_test_system_prompt.md`
4. 选择 `glm-5`
5. 关联知识库
6. 直接提问测试
